# دليل الهوية البصرية ونظام التصميم — InWork

## 1. الهوية

- الاسم المعتمد: **InWork**.
- الوصف: **منصة خدمات تشاركية ذكية متعددة المجالات**.
- يجب أن تعكس الواجهة الثقة والوضوح والتعاون والاختيار، لا أن توحي بأن المنتج مخصص للنقل أو مجال خدمي واحد.
- لا تُستنسخ شعارات أو أصول أو واجهات محمية لمنتجات أخرى. يمكن استعارة مبادئ UX العامة مثل وضوح الطلب والعروض والمقارنة والاختيار.

## 2. لوحة الألوان المعتمدة

- **Primary — أزرق داكن/كحلي:** `#0F172A`.
- **Accent / Action — ذهبي دافئ:** `#F59E0B`.
- **Background — أبيض:** `#FFFFFF` و`#F8FAFC`.
- **Text — رمادي داكن:** `#334155`.
- **Success:** أخضر هادئ للحالات الناجحة فقط.
- **Danger:** أحمر للحذف أو الرفض أو الحالات الحرجة فقط.

لا تغيّر الألوان الأساسية دون قرار هوية صريح. تجنب إدخال ألوان زاهية متنافسة أو تلوين كل بطاقة بلون مختلف.

## 3. الطباعة واللغات

- العربية هي اللغة الافتراضية مع `lang="ar"` و`dir="rtl"`.
- الإنجليزية مدعومة مع اتجاه `ltr` على مستوى المحتوى.
- استخدم خطًا عربيًا واضحًا مثل Cairo أو Tajawal عند إضافتهما محليًا مع التحقق من الترخيص والحجم؛ وإلى ذلك الحين استخدم مكدس خطوط نظام موثوقًا.
- حافظ على تدرج واضح للأحجام والأوزان، وتجنب النصوص الصغيرة منخفضة التباين.

## 4. مكونات النظام

- أزرار أساسية وثانوية وحالات تعطيل وتحميل واضحة.
- حقول ونماذج مع تسميات صريحة ورسائل تحقق مفهومة.
- بطاقات مقدمي الخدمة تعرض التخصص، ونطاق الخدمة، والتقييم، والإنجازات، والتوفر.
- بطاقات العروض تعرض السعر والنطاق والمدة والشروط ووقت الاستجابة.
- شارات التوثيق والتقييمات لا تظهر إلا عندما تكون البيانات موثوقة وموجودة.
- حالات فارغة وأخطاء وتحميل ورسائل تأكيد متسقة.
- النوافذ الحوارية قابلة للإغلاق بلوحة المفاتيح والنقر خارجها، مع تسميات وصول واضحة.

## 5. الحركة والتفاعل

- انتقالات قصيرة غير مشتتة.
- تغذية راجعة فورية بعد كل إجراء.
- احترام إعداد `prefers-reduced-motion`.
- لا تستخدم الحركة أو اللون وحدهما لتوصيل حالة مهمة.
- يجب أن تعمل الواجهة على الشاشات الصغيرة والكبيرة دون فقدان الوظائف.

## 6. قواعد الاتساق

- كل مجال خدمة يستخدم المكونات المشتركة نفسها مع محتوى وحقول تناسب المجال.
- لا تربط التصميم بمدينة واحدة أو مهنة واحدة.
- لا تعرض بيانات تجريبية أو تقديرية على أنها بيانات حقيقية.
