# خريطة رحلة المستخدم (End-to-End User Journey) - In Work

## المرحلة الأولى: الهبوط والاختيار السريع (Landing & Segmentation)
- يزور المستخدم الموقع ويرى بوضوح: **"الخدمات الحرفية المعتمدة في الإسماعيلية فقط"**.
- يظهر له خياران رئيسيان بمستطيلات بارزة:
  1. **أحتاج حرفياً الآن** (للعملاء).
  2. **أنا حرفي / أبحث عن عمل** (لمقدمي الخدمات).

## المرحلة الثانية: خطوات الطلب السريع (أقل من دقيقة)
1. **اختيار المهنة:** (سباكة، كهرباء، تنظيف).
2. **تحديد الموقع:** اختيار المنطقة داخل الإسماعيلية (المنشية، عرايشية مصر، حي ثالث، الشهداء، الفردان، إلخ) مع التقاط الموقع الجغرافي.
3. **تحديد الموعد:** (فوري خلال ساعة / موعد مخصص).
4. **طريقة الدفع:** (إنستاباي، المحافظ الإلكترونية، أو الدفع النقدي عند الاستلام مع إشراف المنصة).
5. **تكيد الطلب:** ظهور شاشة النجاح وتوجيه الطلب لأقرب حرفي متاح.
