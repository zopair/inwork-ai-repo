# دليل الأدوات التقنية المتكاملة - In Work ⚙️
> الهندسة البرمجية والأتمتة الذكية لصفر تكلفة (0% Cost Architecture)

## 1. الواجهة الأمامية (Frontend Tech)
- **Framework:** Next.js (React) + Tailwind CSS للسرعة الفائقة والأرشفة التلقائية.
- **Mobile Experience:** Progressive Web App (PWA) ليعمل التطبيق كأنه تطبيق موبايل حقيقي دون الحاجة لتاجر المتاجر في المرحلة الأولى.
- **Maps:** Leaflet.js + OpenStreetMap مجاناً لتتبع الحرفيين في الإسماعيلية.

## 2. الخوادم وقاعدة البيانات (Backend & Database)
- **Database / Auth:** Supabase (PostgreSQL) لإدارة حسابات الحرفيين والعملاء بأمان مشفر.
- **Hosting:** Cloudflare Pages (Global CDN مجاني ومؤمن بشهادة SSL).

## 3. الذكاء الاصطناعي والروبوتات (AI & Automation Bots)
- **AI Engine:** نماذج Gemini & ChatGPT لتوليد النصوص، تحسين تجربة المستخدم، والمطابقة الذكية.
- **Automation Bots:** GitHub Actions لعAN تشغيل اختبارات الأمان، الرفع التلقائي، ومراقبة حالة الخوادم 24/7 دون تدخل بشري.
